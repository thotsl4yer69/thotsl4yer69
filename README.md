# Jack Mazzini / MAZLABZ

**AI-assisted technical product developer and systems integrator** working across edge AI, embedded hardware, automation, Android and rapid prototyping.

I build experimental systems that cross the boundary between software and the physical world. My public work is presented with its maturity and provenance intact: prototypes are labelled as prototypes, research forks retain upstream credit, and AI assistance is disclosed.

## Selected systems

- **[Sentient Core](https://github.com/thotsl4yer69/sentient-core)** — privacy-first local AI assistant architecture for NVIDIA Jetson, combining local inference, speech, memory and service orchestration. *Active prototype.*
- **[DRIFTER](https://github.com/thotsl4yer69/drifter)** — Raspberry Pi vehicle intelligence research spanning OBD-II/CAN telemetry, diagnostics, logging, alerts and dashboard output. *Active prototype.*
- **[HexPlayer](https://github.com/thotsl4yer69/Hexplayer)** — physical NFC album tiles mapped to Spotify playback through a headless Raspberry Pi service. *Working prototype.*
- **[Mixdown](https://github.com/thotsl4yer69/mixdown)** — Android feed and media-system experiments involving React Native, Kotlin, native media integration and adaptive ranking. *Active prototype.*
- **[Pigeonhole](https://github.com/thotsl4yer69/pigeonhole)** — self-hosted streaming and Kodi integration work, supported by related repository and distribution experiments. *Lab project.*
- **[Myceliyum](https://github.com/thotsl4yer69/Myceliyum)** — mobile fungi and field-mapping experiments. *Lab project.*
- **[Akari Android](https://github.com/thotsl4yer69/akari-android)** — local-first Kotlin / Jetpack Compose application with Android CI and emulator validation. *App prototype.*
- **[THOTSL4YER69 Game](https://github.com/thotsl4yer69/thegame)** — playable Phaser / TypeScript game with Android packaging and production-build checks. *Interactive prototype.*

## Working method

- Evidence before claims: architecture, source, setup notes, screenshots, hardware and tests where available.
- Systems integration: connecting models, services, sensors, APIs, data and interfaces into inspectable prototypes.
- AI-native development: AI tools accelerate research and implementation; architecture, integration, verification and product decisions remain human-directed.
- Provenance first: forks and upstream-derived research are identified as such and are not presented as original products.

## Current direction

I am available for bounded prototype work, technical discovery and systems-integration problems involving AI, software and real-world devices.
